# PhishingGuardian

Система для выявления вероятности фишинга по url-адресу.

Для обучения модели Catboost составлен следующий корпус данных:

Из [датасета](https://www.kaggle.com/datasets/taruntiwarihp/phishing-site-urls) были извлечены лейблы с меткой good - это означает, что URL-адреса не содержат вредоносного контента.
Для получения ссылок на фишинговые сайты был использован сервис [PhishTank](https://phishtank.org/developer_info.php)
В итоге получилось собрать 154000 записей

Основным предположением о качественном обучении стала мысль, что фишинговые ссылки (даже те, что мимикрируют под реальные сервисы) представляют из непредсказуемо распределенный набор символов. Были отдельно посчитаны энтропия Шеннона для домена и для всей ссылки для каждого адреса, плюсом были извлечены и другие фичи, которые, как мне кажется, должны повлиять на результаты.

Таким образом, решаем задачу бинарной классификации и предсказываем вероятность "фишинговости" ссылки.

Для валидации была выбрана метрика roc-auc. 
Итоговая метрика: 0.9544
